# Frontend

Next.js + React + TypeScript + TailwindCSS application. Data fetching via
React Query, client state via Zustand.

Not yet scaffolded — the Next.js app is created in Phase 1 (Architecture),
where we decide on the internal folder structure
(`/components`, `/features`, `/hooks`, `/lib`, `/services`, `/context`,
`/types`, `/styles`) and app-router conventions.
